How was it made?

Built with Claude over several conversations, so there is no single original prompt. This one is a starting point for a similar page:

Build a single-file interactive HTML page for a graduate seminar, EPOL 590: AI and Academic Literature. Each student adds their name, up to five research interests and a one-sentence research topic. Show the class as a slowly rotating 3D network: the course at the centre, each interest as a coloured hub, and students linked to the hubs they share. For each interest, fetch a few recent papers from the OpenAlex API and attach them to its hub as small nodes in the same colour. Clicking a paper shows its title, authors, year, abstract and a link to the full article; clicking a student shows their topic and who shares their interests. Use only HTML, CSS and JavaScript in one file.

One HTML file can’t share entries between students on its own · Iterate one change at a time · Check every paper against the source

Students asked for the prompt behind the Week 1 class constellation. It was built with Claude over several conversations, so there isn’t one original prompt; this is a starting prompt that produces a similar page. Two caveats, as in lecture-2.md: a single HTML file can’t share entries between students by itself, so a shared class map needs shared storage, such as a Claude artifact’s database or a small server; and iterate one change at a time, checking every paper it shows against the source.
