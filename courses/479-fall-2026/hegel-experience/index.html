The course question · human and machine learning

What, exactly, would the machine learn?

You did not merely collect more readings of the lamp. You changed what you were willing to count as knowing it: a present appearance, a continuing thing, a relation that makes different appearances intelligible.

Registering the light

A sensor reports the current illumination. That measurement alone does not establish a standpoint for which the reading counts as truth.

Recognizing the lamp

A classifier identifies the object across changes in lighting. That is a real achievement; it does not by itself show that the system has questioned its own categories.

Learning the dependencies

A system learns which changes make the lamp shine and predicts new cases. This is closer to a relational account, but predictive success alone does not settle the question of experience.

When a prediction fails, does the system only correct an answer—or does it revise what the object is and what would count as knowing it? What evidence would let us tell?

These are comparisons of functions, not a claim that sensors, classifiers, and causal models literally instantiate Hegel’s three shapes of consciousness.
