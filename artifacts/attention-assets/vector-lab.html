Several heads, several mixtures

Heads run in parallel. Each has its own learned transformations. They are not assigned jobs like “grammar” or “emotion” in advance.

The paper uses 8 heads with 64 features per head in its base model. This miniature uses 8 heads with 2 features each. A real layer joins the head outputs and transforms them again; it also includes residual connections, normalization, and a feed-forward sublayer.

The jargon, translated

Query · Q
The current token’s numerical comparison vector.
Key · K
Each source token’s numerical comparison vector.
Value · V
The information vector each source contributes to the mixture.
Softmax
Turns scores into positive shares that sum to one. Larger scores get larger shares.
Head
One set of Q, K, and V transformations and its attention calculation.
See the calculation behind the picture

softmax(QKᵀ / √dₖ)V

Multiply corresponding query and key features, add them, and divide by the square root of the key’s feature count (here, √2). Softmax turns those scores into weights. Multiply each value by its weight, then add. In a trained model, Q, K, and V come from learned projections of token representations.
